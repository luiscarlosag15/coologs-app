Coologs - Fridge Logs Analysis Tool 🧊📊
Coologs is a desktop application for Field Specialists and Support Engineers to quickly parse and analyze log packages (.zip) from cobas p 501 and cobas p 701 post-analytic storage units.

🌟 Key Features
Automated Log Parsing: Fast extraction of log archives and hardware generation identification (LTE, Unified, PLC, First).

Multi-Core Diagnostics: Scans log files using customizable error rules, keywords, and time range filters.

Interactive Context Viewer: Deep-dive log inspection with colorized syntax highlighting and font zoom controls.

Workflow Analytics: Aggregates tube throughput statistics and displays graphical performance charts.

Firmware Compliance: Automatically checks installed component versions against compatibility matrices.

Cloud Sync & Updates: Synchronizes diagnostic rules and receives automatic updates via Supabase.

Exporting: Generates formatted PDF reports and exports LLM-ready context for AI troubleshooting.

🚀 Quick Start
Download the latest Coologs.zip release from Releases.

Extract the archive into a local folder.

Launch Coologs.exe.
